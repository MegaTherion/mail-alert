📋 CAMBIOS REALIZADOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  PUERTO SSH PARAMETRIZABLE 🔌

   ❌ ANTES: Puerto hardcodeado a 22
   ✅ AHORA: Puerto dinámico con fallback

   Características:
   • Detecta SSH_PORT del secret
   • Default 22 si no está configurado
   • ssh-keyscan con puerto correcto
   • SSH config con puerto dinámico

   Cómo usar:
   • Puerto 22 → NO agregar secret SSH_PORT
   • Otro puerto → Agregar secret SSH_PORT = 2222


2️⃣  SOPORTE MÚLTIPLES TIPOS DE CLAVE 🔑

   ❌ ANTES: Solo RSA hardcodeado a ~/.ssh/id_rsa
   ✅ AHORA: RSA o ED25519 automáticamente

   Soporta:
   • ED25519 (moderno, rápido) ← Recomendado
   • RSA 4096 (compatible, amplio)

   Cómo usar:
   ```bash
   # ED25519
   ssh-keygen -t ed25519 -f deploy_key -N ""

   # RSA
   ssh-keygen -t rsa -b 4096 -f deploy_key -N ""

   # Ambos funcionan igual con el workflow
   ```


3️⃣  SSH CONFIG LIMPIO 🏗️

   ❌ ANTES: Flags esparcidos en comandos
   ssh -i ~/.ssh/id_rsa -p 2222 user@host "cmd"

   ✅ AHORA: Archivo SSH config centralizado
   Host deploy-server
     HostName ${{ secrets.SSH_HOST }}
     Port ${{ secrets.SSH_PORT || 22 }}
     User ${{ secrets.SSH_USER }}
     IdentityFile ~/.ssh/deploy_key
     StrictHostKeyChecking accept-new
     ConnectTimeout 10

   Ventajas:
   • Más limpio y legible
   • Configuración centralizada
   • Más fácil debuggear
   • Mejor manejo de timeouts


4️⃣  HOST KEY VERIFICATION AUTOMÁTICA 🔒

   ✅ Agrega host a known_hosts automáticamente
   ✅ Usa puerto correcto en ssh-keyscan
   ✅ StrictHostKeyChecking=accept-new
   ✅ ConnectTimeout de 10 segundos


5️⃣  CLEANUP MEJORADO 🧹

   ❌ ANTES: Solo rm -f ~/.ssh/id_rsa
   ✅ AHORA: Limpia todo lo temporal

   Elimina:
   • ~/.ssh/deploy_key (clave privada)
   • ~/.ssh/config (SSH config)
   • ~/.ssh/known_hosts (hosts conocidos)

  □ ALERT_SECRET         ← Tu secret de app

CASO 1: Puerto 22 (default), ED25519
┌─────────────────────────────────────────────────────┐
│ 1. Generar:                                         │
│    ssh-keygen -t ed25519 -f deploy_key -N ""        │
│                                                     │
│ 2. Copiar al servidor:                             │
│    ssh-copy-id -i deploy_key.pub user@servidor     │
│                                                     │
│ 3. Secrets GitHub:                                 │
│    SSH_PRIVATE_KEY = [deploy_key content]          │

│                                                     │
│ 2. Copiar al servidor:                             │
│    ssh-copy-id -i deploy_key.pub -p 2222 \         │
│      user@servidor                                 │
│                                                     │
│ 3. Secrets GitHub:                                 │
│    SSH_PRIVATE_KEY = [deploy_key content]          │

│    SSH_PROJECT_PATH = /var/www/mail-alert          │
│    ALERT_SECRET = tu_secret                        │
│    SSH_PORT = 2222                    ← AGREGAR    │
└─────────────────────────────────────────────────────┘

CASO 3: IP + Puerto custom, ED25519

│ 1. Generar:                                         │

🔄 FLUJO DE EJECUCIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Setup SSH
   • Detecta puerto (secret o default 22)
   • Agrega host a known_hosts (con puerto correcto)
   • Guarda clave privada (RSA o ED25519)
   • Crea SSH config con toda la configuración
   • Set 600 permisos

2. Deploy via SSH
   • ssh deploy-server (usa todo desde config)
   • Determina hostname, port, user, key automáticamente
   • Conecta con timeout de 10s
   • Ejecuta comandos de deploy

3. Verify
   • ssh deploy-server (usa config)

4. Cleanup
   • Elimina deploy_key, config, known_hosts

🆚 COMPARACIÓN: ANTES vs DESPUÉS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CARACTERÍSTICA          ANTES              DESPUÉS
─────────────────────────────────────────────────────
Puertos SSH            Solo 22             Cualquier puerto
Tipos de clave         Solo RSA            RSA o ED25519
SSH config             Flags dispersos     Archivo config
Host verification      Manual              Automática
Clave hardcodeada      ~/.ssh/id_rsa       ~/.ssh/deploy_key
Timeout                No                  10 segundos
Fallback puerto        No                  Default 22
Flexibilidad           Baja                Alta
Seguridad              Media               Alta
Limpieza               Parcial             Completa
