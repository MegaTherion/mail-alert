    "secret": "tu_ALERT_SECRET",
    "rule": "Rule Name",
    "priority": "emergency|high",
    "from": "sender@example.com",

🔐 FCM INTEGRATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Automaticamente:

1. POST /api/mail-alert valida secret
2. FCMService genera JWT con RS256
3. Obtiene access token de Google OAuth2
4. Envía notificación a topic "mail-alerts" via FCM v1 HTTP API
5. Configura Android priority según alert priority
6. Actualiza sent_at si successful

Priority Mapping:
  emergency → android.priority=high, channel_id=emergency_channel
  high → android.priority=high, channel_id=alert_channel

  SSH_PATH       → Public HTML path (e.g., /home/user/public_html)

Workflow (.github/workflows/deploy.yml):
  1. Checkout code
  2. Setup SSH
  3. Deploy: git pull → composer install → config:clear → migrate
  4. Cache optimization
  5. Set permissions
  6. Cleanup SSH
